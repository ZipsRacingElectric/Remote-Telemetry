This project is for the collection of and transmission of real-time telemetry
for use in the Zips Racing Team cars.

# Getting Started
To develop or build this project you will need a dev environment with
[Rust](git@github.com:ZipsRacingElectric/Remote-Telemetry.git) installed.
In order to flash a device, we use
[probe-rs](git@github.com:ZipsRacingElectric/Remote-Telemetry.git)

# Hardware References
The hardware used in this module consists of the following:
 - ESP32-C6: main processor
    - [Datasheet](https://documentation.espressif.com/esp32-c6_datasheet_en.pdf)
    - [Reference Manual](https://documentation.espressif.com/esp32-c6_technical_reference_manual_en.pdf)
 - easyRadio eRIC-LoRa Long Range Datasheet
    - [Datasheet](https://lprs.co.uk/assets/files/eRic_LoRa_Datasheet_V1.44.pdf)
